## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in `Saif807380/self-hosted-apps` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: root `docs/adr/` for system-wide decisions, plus a `CONTEXT.md` + `docs/adr/` per app (`pitwall`, `streamcloud`, `trove`). See `docs/agents/domain.md`.
